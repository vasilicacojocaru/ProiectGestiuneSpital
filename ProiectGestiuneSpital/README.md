# Aplicație de gestiune a unui spital

Proiect realizat în C++ pentru disciplina Programare Orientată pe Obiecte.

## Descriere

Aplicația permite gestionarea informațiilor dintr-un spital:
- pacienți;
- medici;
- asistenți;
- programări;
- internări;
- facturi.

## Funcționalități

- Afișare pacient
- Afișare medic
- Afișare asistent
- Creare programare
- Emitere factură
- Internare pacient
- Filtrare pacienți după diagnostic
- Adăugare pacient
- Afișare toți pacienții
- Statistici spital
- Salvare pacienți în fișier text
- Logging pentru operațiuni importante

## Concepte POO folosite

- Clase și obiecte
- Încapsulare

## Rulare proiect

Proiectul se rulează din Visual Studio 2022.

Pași:
1. Se deschide soluția în Visual Studio.
2. Se compilează cu Ctrl + Shift + B.
3. Se rulează cu Ctrl + F5.
