# Aplicație de gestiune a unui spital

## Descriere
Aplicație realizată în C++ pentru gestionarea activităților unui spital.

## Funcționalități
- Gestionare pacienți
- Gestionare medici
- Gestionare asistenți
- Programări medicale
- Internări
- Facturi
- Filtrare după diagnostic
- Statistici

## Concepte OOP utilizate
- Încapsulare
- Moștenire
- Polimorfism
- Abstractizare

## Tehnologii
- C++
- STL (vector)
- Git
- GitHub
